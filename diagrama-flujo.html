Cómo fluyen los datos (en palabras simples)

No hay backend, API ni base de datos. App.tsx mantiene una sola variable de estado (currentView) que decide qué bloque JSX se renderiza. Todo el contenido —nombres de doctores, fechas, documentos, historial— está escrito directamente en el JSX como texto/valores fijos (no hay props que viajen entre componentes porque solo existe un componente). La "navegación" entre pantallas ocurre cuando el usuario hace click en una tarjeta o botón, que llama a setCurrentView(...) y React vuelve a renderizar el bloque correspondiente. La dependencia @google/genai está declarada en package.json pero no se usa en ningún archivo de src/ — es un remanente del scaffold de Google AI Studio.
